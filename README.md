# Elite Furniture

React furniture storefront with product management, collections, product details, cart and authentication screens.

## Project structure

- `src/pages/`
- `src/admin/ProductManagement.jsx`
- `src/redux/cartSlice.js`
- `src/components/`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/Elite-Furniture.git
cd Elite-Furniture
```



Install Node.js and npm, then run `npm install` and `npm run dev` in the application directory. Open the terminal URL.
